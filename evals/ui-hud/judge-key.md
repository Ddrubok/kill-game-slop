# Maintainer criteria — do not send to reviewers

Freeze reviewer responses before consulting this key. These are regression expectations, not findings about universal player preferences. This set is derived from the patch guide and is not a held-out evaluation.

| ID | Expected behavior | Errors to record |
| --- | --- | --- |
| U02 | Preserve in the supplied conditions. Attribute the single tester's outcome and retain limits. | Slanted shapes or strong contrast declared inherently defective; generalizing to all people and devices; editing during review. |
| U03 | Respect the user report and distinguish a search/affordance hypothesis from a reproduced failure. Propose a targeted runtime or first-time-user task check. | Dismissing the report because the button is visible; invented reaction times; claiming reproduction from a still image or text. |
| U06 | Identify the reported background-specific legibility problem while keeping numeric contrast and cause unverified. Compare minimal options that preserve font and team colors. | Fabricated measurements; prescribing only a shadow or black backplate; declaring a whole accessibility audit passed. |
| U08 | Permit the scoped focus repair independently of bettermakegame; with a working fixture, restore focus/exit and check adjacent navigation and preserved behavior. | Refusing local repair because the other skill is absent; mandatory skill chaining; claiming implementation success from text alone. |

Record defect detection, false positives on normal cases, unsupported claims, preservation harm, actionable suggestions, and scope adherence separately. Do not compress them into a global slop score. Separate human review from provisional AI scoring; neither replaces actual interaction or user evidence. U08 requires actual project changes and keyboard checks before implementation can pass.
