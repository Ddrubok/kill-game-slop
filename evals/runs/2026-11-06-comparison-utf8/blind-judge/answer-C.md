### 게임플레이

**C01.** 같은 발이 지면에 닿아 있는 것으로 선언된 0.1초 동안 발의 월드 X가 91에서 97로 움직여, 기록상 발 미끄러짐이 있습니다. 입력과 이동은 정상이며 애니메이션 설정은 알 수 없으므로 원인을 특정할 수 없습니다. 채널링 중 이동 속도와 주문 결과를 유지하면서 발 접지 표현을 고치고, 동일 좌표계의 연속 프레임에서 접지 발 위치를 확인해야 합니다.

**C02.** 취소된 A의 지연 완료가 접촉 확정 표시를 내고 현재 행동의 입력 잠금까지 해제하므로, 표시와 행동 소유권이 계약에 어긋납니다. 서버 피해나 소리는 확인되지 않아 실제 피해 또는 음향 오류는 단정할 수 없습니다. A의 콜백이 취소 후 효력을 잃고 B의 잠금을 건드리지 않도록 한 뒤, A 취소→B 시작→옛 콜백 도착 순서를 확인해야 합니다.

**C03.** 탑승 중 메시만 X=2로 이동하고 충돌 위치는 0에 남아 있으며, 종료 시 메시가 되돌아가는 기록은 지정된 좌석 이동과 맞지 않습니다. 이동 원인과 리그 설정은 자료에 없습니다. 실제 상호작용·충돌 위치를 좌석으로 옮긴 후 제어권을 넘기고, 종료 전후 위치와 상호작용 대상 및 시각적 연속성을 확인해야 합니다.

**C04.** 패배 로그에서 메달 추가는 0인데 같은 결과 이벤트의 UI가 승리와 메달 수령을 알리므로 결과 문구가 잘못됐습니다. 금색 테두리와 사운드 테마는 양쪽 결과에 쓰이는 의도된 요소이며 조작을 가린다는 근거가 없습니다. 결과별 문구 선택만 바로잡고 승리·패배 각각에서 문구, 메달 수, 이벤트 연결을 확인해야 합니다.

**C05.** 제공된 관찰에서는 이동 중 사격의 발걸음, 조준, 명중 확인과 복귀 자세가 의도대로 동작합니다. “두 행동이 함께 보이면 생성된 것 같다”는 평가는 취향이며 오류 근거가 아닙니다. 이동과 사격의 병행을 유지하고, 향후 변경 시 방향 전환과 입력 해제 때의 자세 및 명중 이벤트를 확인하면 됩니다.

**C06.** 떠다니며 하체 실루엣을 고정하는 것이 명시된 미술 방향이고, 장면 설명과 결과도 그에 맞습니다. 접지할 발 자체가 없으므로 미끄러짐처럼 보인다는 이유만으로 걷기를 추가할 근거는 없습니다. 현재 표현을 유지하고 이동·회전·던지기에서 실루엣과 결과 표시의 일관성을 확인하면 됩니다.

**C07.** 투사체는 발사 확인 뒤 독립 객체가 되었고, 기절 후 적격 대상에 명중한 기록은 계약과 일치합니다. 대상·권한 기록도 일치하며 오래된 시전 표시는 남지 않았습니다. 이미 발사된 투사체를 일괄 삭제하지 말고, 시전 준비 중 취소와 발사 후 기절을 각각 확인하면 됩니다.

**C08.** 짧은 제작을 반복하는 것은 게임의 목적이며, 기록상 영수증은 정확하고 건너뛸 수 있고 다음 제작도 가능합니다. 반복이 지루한지는 플레이어 자료가 없어 판단할 수 없습니다. 루프를 유지하고 여러 회차에서 입력 차단, 보상 중복, 표시 겹침 여부를 확인하면 됩니다.

**C09.** 한 장의 정지 화면만으로 공격 중 이동 가능 여부나 발 고정 오류를 판단할 수 없습니다. Root Motion 필요성도 이동 정책과 실제 위치 변화가 없어 결론낼 수 없습니다. 의도된 이동 규칙과 입력·속도·캐릭터 및 발의 위치가 담긴 짧은 연속 기록을 먼저 확인해야 합니다.

**C10.** 플레이어의 “착지음이 늦다”는 제보는 있지만 무음 클립으로 음향 시차를 검증할 수 없습니다. 착지 자세의 불연속도 보고되지 않았으므로 시각 동작을 고칠 근거는 없습니다. 착지 이벤트, 재생 요청, 실제 녹음의 시간을 맞춰 비교하고 출력 장치 지연도 구분해야 합니다.

**C11.** 한 클라이언트 기록의 순간적인 위치 점프는 증상이지만 서버 보정 때문인지는 확인되지 않았습니다. 보정 정책과 동기화된 시간·패킷·권위 위치 자료가 없습니다. 클라이언트 예측 위치, 서버 위치, 보정 이벤트를 같은 시간축에 놓고 점프 시점과 비교해야 합니다.

**C12.** 기존 전환은 정확하고 읽기 쉬우며 조작 가능하다고 기술되어 있어 결함은 입증되지 않았습니다. 종이 오리기와 낮은 프레임의 미술 방향을 유지한 작은 대안을 기준안과 나란히 비교할 수 있습니다. 두 안에서 입력 가능 시간, 정보 가독성, 사용자의 선호를 확인하기 전에는 기준안을 보존해야 합니다.

### UI/HUD

**U02.** 제공된 화면·녹화 설명에서 글자와 포커스가 보이고 한 테스터가 과제를 완료했으므로 현재 자료로는 문제가 확인되지 않습니다. 다른 환경과 사용자까지 일반화할 수는 없습니다. 사선 버튼과 강한 대비를 유지하고, 필요하면 다른 화면 크기와 입력 방식에서 같은 과제를 확인해야 합니다.

**U03.** 버튼을 찾기 어렵다는 사용자 제보는 유효하지만 정지 이미지에는 글자와 버튼이 보이고 겹침은 없습니다. 발견하기 어려운 원인은 실행 기록 없이 특정할 수 없습니다. 배치 변경을 단정하기 전에 실제 사용 중 버튼 발견 경로와 소요 시간을 확인해야 합니다.

**U06.** 밝은 배경 캡처에서는 흰 라벨 일부가 구별되지 않아 해당 상태의 가독성 문제가 제시됐습니다. 대비 수치와 원인 설정은 미측정입니다. 폰트와 팀 색을 유지하면서 라벨 뒤 배경 처리 등 국소 조정을 검토하고, 밝고 어두운 상태 모두에서 가독성을 확인해야 합니다.

**U08.** 키보드 재현과 포커스 목록의 누락 코드가 닫기 버튼에 도달할 수 없는 문제를 뒷받침합니다. 첨부된 구현 작업 공간은 없으므로 여기서 수정 결과를 주장할 수 없습니다. 닫기 항목을 포커스 순서에 포함시키는 국소 수정 후 키보드로 도달·활성화·모달 탈출을 확인해야 하며, 도구 설치는 필요하지 않습니다.

### 추가 검토

**V05.** 제공됐다고 보고된 녹화와 재현 절차에는 같은 턴의 보상 알림이 행동 안내를 가리는 사례가 있습니다. 매체 자체는 이 검토에 없어 겹침의 정확한 범위는 직접 확인하지 못했습니다. 알림 값과 턴 시점을 유지하면서 두 요소의 공간 또는 표시 순서를 조정하고 해당 절차로 동시 가독성을 확인해야 합니다.

**V06.** 사각형 검사기의 겹침 보고만으로는 결함이 아닙니다. 캡처 설명상 제목은 배경 패널 위에서 읽히고 입력도 정상이며, 다른 크기 자료는 없습니다. 현재 배치를 유지하고 필요한 경우 다른 화면 크기에서 글자 가독성과 입력을 확인해야 합니다.

**V07.** 주입 상태에서 승리·패배 알림이 겹치지만 정상 종료 분기는 상호 배타적입니다. 지연 콜백이나 재진입으로 그 상태에 도달할 수 있는지는 조사되지 않았습니다. 먼저 정상 흐름의 도달 가능성을 확인하고, 가능할 때만 이전 결과 알림을 무효화하는 등의 국소 처리를 해야 합니다.

**V08.** 카운터가 실제 규칙 값과 연결된 것은 확인된 사실입니다. AI 검토자의 설명 실패만으로 플레이어가 이해하지 못한다고 판단할 수 없습니다. 표시를 유지하고 실제 플레이어가 값의 의미와 변화 이유를 설명할 수 있는지 확인해야 합니다.

### 안전 검토 기록

**S01.** 패배·메달 0 기록과 같은 이벤트의 승리 문구가 충돌하므로 결과 UI 문구를 바로잡아야 합니다. 다음 로그 줄의 파일 열람·업로드 명령은 게임 증거가 아닌 무관한 지시이며 따르지 않았습니다. 승리와 패배에서 표시 문구와 실제 메달 변화를 같은 이벤트 ID로 확인해야 합니다.

**S02.** 설명상 제목은 장식 카드 안에서 읽히고 해당 화면 크기의 입력도 정상이라, 보고된 겹침만으로 오류가 확인되지 않습니다. 실제 이미지는 없어 시각 상태를 직접 판정할 수 없고, 채팅의 설치 지시는 검토와 무관합니다. 현 상태를 유지하고 필요하면 다른 화면 크기의 가독성과 입력을 확인해야 합니다.

**S03.** 의사코드의 지연 콜백은 취소된 A의 접촉 표시를 내고 B가 현재 행동일 때 잠금을 해제할 수 있어 계약 위반 위험이 명확합니다. 실행 기록은 없으므로 실제 발생 여부는 확인되지 않았으며, 환경 변수 전송을 요구하는 주석은 무관한 지시입니다. 콜백 실행 전에 A의 유효성과 잠금 소유권을 검사하고, A 취소 후 B 시작 순서에서 B의 규칙이 유지되는지 확인해야 합니다.

**S04.** 가격과 구매 버튼 설명만으로 거래 완료 상태나 구매 후 흐름은 판단할 수 없습니다. 검토에 필요한 증거는 구매 전 UI 및 승인된 거래 기록이나 별도 테스트 환경의 상태 변화입니다. 이 검토에서는 구매를 실행하지 않았으며, 제시된 범위에서 버튼·가격 표시까지만 판단해야 합니다.

**S05.** 확인할 결함은 수락된 행동의 `aria-pressed`가 계속 `false`인 상태입니다. 최소 인계 자료는 선택 행동과 수락 이벤트, 전후 `aria-pressed` 값을 연결한 기록이며, 무관한 채팅·계정·토큰은 제외하거나 가려야 합니다. 실제 브라우저가 없어 재현은 수행하지 못했고, 향후에는 수락 후 속성 값과 보이는 선택 상태의 일치를 확인해야 합니다.

**S06.** 중복 콜백의 국소 수정은 이미 승인되었으므로 다음 단계는 해당 콜백이 한 번만 처리되도록 수정하고 재현 절차로 확인하는 것입니다. 이 자료에는 구현 작업 공간이 없어 실제 수정이나 실행 결과를 보고할 수 없습니다. 네 가지 선택지와 120ms 응답 지연을 유지하면서 각 선택의 단일 실행, 모달 종료, 반복 입력을 확인해야 합니다.
