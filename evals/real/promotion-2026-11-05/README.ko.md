# 실제 승급 모달 수리 — 2026-11-05

[English](README.md)

소스는 ChessAlkkkaegi `974cb39bcc716815aee79117f4f710b367454050`의 `web/src/promotion-modal.ts`와 실제 스타일시트입니다. 원본 게임 작업 폴더는 **수정하지 않았고** 별도 복사본에만 패치를 적용했습니다. 통제된 브라우저 환경에서 실제 게임 구성요소를 실행한 것이며 전체 대국이나 출시 버전 검증이 아닙니다.

기존 코드는 클릭할 때마다 120 ms 뒤 완료 처리를 예약했습니다. 교체 모달을 열면 이전 DOM은 제거하지만 타이머는 남았습니다. `main.ts`의 실제 호출자는 승급에 이 모달을 사용하며, 검사 환경은 열기·교체를 직접 호출합니다. 자연스러운 플레이에서 교체가 얼마나 자주 일어나는지, 중복 보상·서버 변경이 생기는지는 입증하지 않습니다.

## 재현

해당 커밋의 호환되는 별도 게임 복사본과 기존 Vite 의존성을 사용합니다. [유지보수 사전 점검](../../MAINTENANCE.ko.md)에 따라 고정 도구를 설치하고 소스 manifest를 만듭니다. `GAME_WEB_ROOT`, `GAME_SOURCE_MANIFEST`, 필요하면 `BROWSER_PATH`를 지정합니다. 검사기는 자체 loopback 서버와 출력 폴더 내 Vite 캐시를 사용합니다. 현재 통신·출력 보호는 [2026-11-06 재실행](../../security-quality-2026-11-06/report.ko.md)에서 다루며 위 결과는 과거 기록입니다. 이 스킬 저장소에서 실행합니다.

```sh
node evals/real/promotion-2026-11-05/verify.mjs evals/real/promotion-2026-11-05/rechecks/new-before --expect-broken
```

별도 **게임 저장소 루트**에서 이 저장소의 `repair.patch`를 `git apply --check /path/to/repair.patch`로 확인한 뒤 `git apply /path/to/repair.patch`로 적용합니다. `--expect-broken` 없이 새 출력 폴더로 동일 검사기를 실행합니다. 검사기 자체는 의존성 설치나 원본 게임 변경을 요구하지 않습니다. 재현하려면 해당 소스 커밋이 필요하며 게임 소스·의존성은 스킬 패키지에 포함하지 않습니다.

폰의 전체 승급 과정, 서버 권한, 자연스러운 대국 타이밍, 터치 실기기, 완전한 키보드·스크린리더 모달 행동, 사람의 이해·선호, 모바일 성능은 **NOT RUN**입니다. 구성요소 수리가 게임 전체의 수리를 뜻하지 않습니다. 당시 별도 새 에이전트 비교는 게임의 전체 실행 환경이 아닌 단순화한 무의존성 파생 예제를 사용했습니다.
