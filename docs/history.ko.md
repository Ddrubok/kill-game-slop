# 날짜별 개발 이력

[English](history.md) · [현재 기능](../README.ko.md)

각 기록은 해당 날짜 버전에 대한 결과이며 최신 스킬의 측정값이 아닙니다. 원본 증거는 기존 보관 위치에 유지합니다.

## 2026-11-09

[실제 게임·참조 선택 후속 평가](../evals/runs/2026-11-09-real-routing/report.ko.md)는 새 코스메틱 표본과 기존 승급 대조 사례를 구분하고 이미지 직접 첨부를 포함한 새 세션 8개와 선택적 참조 읽기를 기록합니다. 정확도·토큰 절감 우위를 입증하지 못했습니다. README를 재구성하고 조건부 참조 두 곳에 대표·예외 사례의 표본 선정 안내를 추가했습니다.

아트·콘텐츠 확장으로 자산·서사·전체 게임 참조를 조건부로 추가했습니다. [예비 평가](../evals/art-content-2026-11-09/README.ko.md)는 직접 만든 이미지·데이터와 AI 평가 1회를 사용했으며 실제 게임 9개 검증이 아닙니다. 공개된 Windows 검증에서는 브라우저 테스트 3개를 포함해 검사 도구 테스트 10개가 통과했습니다. 정적 무결성과 예제 재실행은 진단 정확도를 측정하지 않습니다.

## 2026-11-06

[실제 수정 비교](../evals/runs/2026-11-06-repair-comparison/report.ko.md)는 알려진 승급 구성요소 하나를 네 조건에서 세 번씩 실행했습니다. 공개한 시각 판정 보정 1건 이후 모든 조건이 기능 검사 3/3을 통과했습니다. **2026-11-06 당시 버전**의 전체 스킬은 이전 전체 스킬보다 총 토큰 중앙값이 51.6%, 경과 시간이 33.2% 감소했고, 비캐시 입력은 21.2% 증가했습니다. 기능과 관찰된 쓰기 범위를 함께 충족한 결과는 2/3이었습니다. 금전 절감이나 이후 아트·콘텐츠·표본 선정 개정판의 측정값이 아닙니다.

[합성 사례 비교](../evals/runs/2026-11-06-comparison-utf8/report.ko.md)는 같은 C/U/V/안전 사례 26개에 일반 요청·짧은 지침·전체 스킬을 각각 한 번 적용했습니다. 모두 AI 예비 채점 기준을 충족했고, 전체 스킬의 누적 입력 토큰은 짧은 지침의 2.42배였습니다. 안정적인 효과나 비용 순위를 입증하지 않습니다.

[v2 대응](../evals/review-v2-2026-11-06/report.ko.md)과 [보안·품질 기록](../evals/security-quality-2026-11-06/report.ko.md)은 검사기 수정, 검토 자료의 신뢰 경계, 범위 제한 수집, 브라우저 요청 정책, 기존 증거 덮어쓰기 방지를 다룹니다. [유지보수 명령](../evals/MAINTENANCE.ko.md)으로 재실행할 수 있습니다. 검사 도구와 기록 무결성에 대한 확인이며 전체 게임 품질 판정이 아닙니다.

## 2026-11-05

- [실전 검증](../evals/practical-validation-2026-11-05.ko.md)에서 예제의 오래된 콜백과 실제 선택 구성요소를 수정했습니다. 짧은 지침과 전체 스킬 모두 작업을 해결하고 축하 연출을 보존했습니다. 원본 게임 프로젝트는 수정하지 않았으며 정확도 우위는 입증하지 못했습니다.
- [행동 일관성 평가 자료](../evals/gameplay-coherence-2026-11-05/README.ko.md)에 사례 12개와 별도 채점 기준을 추가했습니다. 행동·상태·움직임·접촉을 의도된 규칙과 비교하며, 더 넓은 규칙 변경은 허가되지 않으면 선택적 설계 제안으로 남깁니다.
- [인계](../evals/handoff-2026-11-05.ko.md)는 범위와 증거·보존 조건을 선택적 연계 스킬에 전달합니다. 전용 인계 행동 평가와 사람 대상 평가는 미실행입니다.
- [피드백 수정](../evals/feedback-repair-2026-11-05.ko.md)으로 예시를 중립화하고 한국어 발견 문구와 메타데이터를 추가했으며, 조건부 실행 지침을 진입 문서에서 분리하고 비공개 경로 의존성을 제거했습니다. 설치 폴더에도 MIT 라이선스를 포함했습니다.
