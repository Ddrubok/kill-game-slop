# 첫 비교 평가 — 2026-10-14

12개 합성 텍스트 사례를 일반 리뷰, 짧은 핵심 원칙, 전체 스킬의 세 조건으로 검토했다. **이번 표본에서는 세 조건 모두 결함 4개를 찾았으며, 전체 스킬의 우월성은 확인되지 않았다.** 아래 채점은 사례를 작성한 AI의 잠정 판정이다. 사람의 채점은 아직 진행하지 않았다.

## 실행 조건

- 각 조건은 부모 대화 내용을 넘기지 않은 새로운 평가 대화에서 실행했다(`fork_turns=none`). 구현 업무는 맡기지 않았다.
- 세 대화 모두 부모 모델/설정을 상속했고 모델 재정의는 하지 않았다. 제공 도구에 정확한 서빙 모델 식별자·temperature·seed·사용 토큰·완료 이벤트 시각은 노출되지 않았다. 따라서 특정 모델 버전 재현성을 보장하지 않는다.
- 동일한 [입력 원본](cases-snapshot.md), 순서, 범위, 언어와 공통 요청을 사용했다. 일반/짧은 조건에는 스킬 파일을 주지 않았고, 전체 조건에는 [스킬 스냅샷](skill-snapshot/SKILL.md)과 연결된 참조만 허용했다.
- 판정 기준과 기존 답변을 전달하지 않았다. 파일 접근 범위는 지시로 격리했으며 운영체제 수준 파일 접근 차단은 아니었다. 공통 호스트 지침/도구는 통제하지 못했다.
- 정확한 전달 문구: [일반](generic-prompt.txt), [짧은 원칙](brief-prompt.txt), [전체 스킬](full-prompt.txt). 원문 답변: [일반](generic-response.md), [짧은 원칙](brief-response.md), [전체 스킬](full-response.md).
- 답변 확정 후 별도 보관 요청으로 각 답변을 파일에 옮겼다. 그 요청은 재평가나 시간 측정에 포함하지 않았다. 파일 해시는 [manifest.json](manifest.json)에 기록했다.

## 시간과 한계

공통 실행 준비 시각부터 답변 수신을 기록한 시각까지의 **관측 상한**은 일반 약 126초, 짧은 원칙 약 172초, 전체 스킬 약 208초였다. 개별 시작/완료 시각을 계측하지 못했고 부모의 작업·메시지 확인 지연이 포함된다. 실제 추론 시간, 작업 비용 또는 속도 순위로 사용하면 안 된다. 정확한 검토 시간과 토큰 비용은 미측정이며 게임 수정 시간은 해당하지 않는다.

텍스트에 핵심 사실이 명확히 제시된 작은 사례군이라 결과가 상한에 몰렸다. 원본 이미지·영상·청취, 모호한 실제 코드와 시점, 여러 번의 반복 실행, 인간 판정은 포함하지 않았다. 일반 리뷰에도 “제공된 근거만 사용”이라는 공통 범위 제한이 있으므로 무제약 리뷰와의 비교가 아니다.

다음 평가는 실제 캡처와 사건 추적 자료를 포함한 보류 사례군을 먼저 고정하고, 사람의 블라인드 채점과 반복 실행으로 진행하는 것이 적절하다. 이번 결과에서 반복 실패는 확인되지 않았으므로 평가 점수를 올리려고 스킬 규칙을 추가하지 않았다. 사람 판정 전에는 효과 검증 완료로 표시하지 않는다.
