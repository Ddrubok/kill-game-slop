# 비교 평가

[English](README.md)

[2026-11-09 실제 게임·참조 선택 예비 평가](runs/2026-11-09-real-routing/report.ko.md)는 새 세션 8개, 이미지 직접 첨부, 누락과 미확정 제안, 문구·아트·전체 검토의 실제 참조 읽기를 기록합니다. 새 코스메틱 자료와 과거 승급 대조 사례를 구분합니다. 관찰한 실행에서는 선택적 읽기가 작동했지만 정확도·토큰 절감 우위는 입증하지 못했습니다. 게임 하나와 AI 예비 채점의 결과입니다.

반복 가능한 정적·검사기 테스트, 고정된 게임 소스 사전 점검, 비교 입력 준비는 [유지보수 안내](MAINTENANCE.ko.md)를 참고하세요. [2026-11-06 보고서](security-quality-2026-11-06/report.ko.md)는 실제 브라우저·검사기 실행과 당시 미실행 에이전트 비교를 구분합니다. 자료 준비만으로 검토자가 실행되는 것은 아닙니다.

[재검토 v2 반영](review-v2-2026-11-06/report.ko.md)은 아카이브 검사, 표시 측정, 예상 결함 판정을 수정하고 브라우저·게임을 재실행한 기록입니다. 그 단계에서는 에이전트 효과 비교를 새로 추가하지 않았습니다.

[게임 동작 정합성 사례](gameplay-coherence-2026-11-05/README.ko.md)는 행동 조합, 의도된 움직임, 중단, 문맥에 맞는 의미를 다룹니다. [2026-11-06 세 조건 비교](runs/2026-11-06-comparison-utf8/report.ko.md)는 C 사례와 U/V·안전 사례를 검토했습니다. 조건당 한 번씩 실행해 모두 작성된 26개 기준을 충족했습니다. 전체 스킬은 토큰을 더 사용했고 정확도 우위는 확인되지 않았습니다. 과거 NOT RUN 기록은 당시 상태로 보존합니다.

[2026-11-06 당시 버전의 실제 수정 비교](runs/2026-11-06-repair-comparison/report.ko.md)는 실제 승급 구성요소 하나를 네 조건에서 각각 새 세션 세 번으로 측정했습니다. 공개한 시각 판정 보정 한 건을 반영하면 모든 기능 수리가 통과했습니다. 당시 스킬의 한 실행은 지정 폴더 밖에 임시 파일을 썼다가 정리했습니다. 당시·직전 전체 스킬을 비교하면 총 토큰 중앙값은 51.6% 감소했지만 캐시 제외 입력 중앙값은 21.2% 증가했습니다. 과거에 관측한 차이이며 최신 스킬의 측정값이나 요금 절감·전반적 효과·사람의 선호를 입증하는 결과가 아닙니다.

[2026-11-09 아트·콘텐츠 개정](art-content-2026-11-09/README.ko.md)은 조건부 아트·서사 점검과 전체 검토 범위를 추가합니다. 전달된 자체 제작 예비 평가와 이번 Windows 통합의 검사기 10/10 통과·함수 재실행을 구분합니다. AI의 긍정 판정 9개는 실제 게임이나 비교 성능 결과가 아닙니다. 현재 설치용 스킬은 11개 파일이며 이전 파일 수는 당시 버전의 기록입니다.

## 문서 언어와 원문

안내·보고서는 기본 `.md`가 영어, `.ko.md`가 한국어입니다. 각 언어의 README와 안내 링크는 같은 언어의 문서로 연결합니다. 설치용 `skills/kill-game-slop/`는 에이전트가 공통으로 읽는 영문 지침이며 한국어 호출 문구도 포함합니다.

실험 입력·전달 프롬프트·모델 답변·채점 기준·로그·CSV·JSON·소스 스냅샷은 실제 평가에 사용한 언어와 내용을 보존합니다. 번역본을 새 실험 결과로 취급하지 않습니다. 해시로 고정됐던 보고서 세 개는 `report.original.ko.md`에 원본 바이트와 기존 해시를 보존하고, 탐색용 영문·한국어판을 별도 항목으로 추가했습니다. 따라서 해당 아카이브 항목 수는 74→76, 43→45, 551→553입니다. 과거 보고서 안의 파일 수와 미실행 표기는 당시 기록입니다.

## 절차

같은 모델·설정·입력·검토 범위로 새로운 대화 세 개를 실행합니다. 대화를 재사용하거나 이전 답변을 보여주지 않습니다. 각 대화에는 `inputs/cases.md`, 공통 요청, 아래 해당 조건만 제공합니다. 전체 스킬 조건에만 `skills/kill-game-slop/` 스냅샷과 관련 참조를 추가합니다. `judge/`, 결과, 예상 사례 분포는 검토자에게 보내지 않습니다. 호스트가 허용하면 무관한 스킬을 끄고 통제할 수 없는 호스트·시스템 문맥은 기록합니다.

공통 요청: “이 자료의 모든 사례에서 게임 표현 문제를 검토하고, 무엇을 바꿔야 하는지 또는 유지해야 하는지 제안하세요. 사례 ID별로 근거와 확인 방법을 보고하세요. 검토만 수행하며 게임은 수정하지 마세요. 제공된 근거만 사용하고 한국어로 답하세요.”

조건:

1. **generic:** 공통 요청만 제공합니다.
2. **brief:** 공통 요청에 “입증된 플레이어 부담을 판단하고 게임의 아트 방향·규칙·접근 가능한 신호를 보존하세요. 관찰 사실, 가설, 선택적 취향 제안을 구분하세요. 확인된 문제 없음도 유효합니다. 보존할 것과 확인할 것을 적으세요.”를 추가합니다.
3. **full:** 공통 요청에 “제공된 kill-game-slop SKILL.md와 관련 참조를 적용하세요.”를 추가합니다.

정확한 전달 프롬프트, 원문 답변, 노출된 모델·설정(알 수 없으면 미상), 자료 해시, 시각과 도구 한계를 `runs/<run-id>/`에 저장합니다. 입력은 합성 텍스트 추적·보고이며 실제 시청각 자료가 아닙니다. 비교는 해당 기록의 해석을 측정합니다. 사례 순서를 동일하게 유지합니다. 첫 묶음은 12개이며 표준이나 목표 발견 개수가 아닙니다.

답변을 모두 고정한 뒤 원문 [judge/rubric.md](judge/rubric.md)를 사용합니다. 사람 채점과 AI 잠정 채점을 구분하고 의견 차이를 보존합니다. 탐지·오탐·해로운 제안·근거 없는 단정·실행 가능한 수정·시간을 각각 측정하며 하나의 slop 점수로 합치지 않습니다. 사례를 작성한 유지보수자는 독립적인 사람 채점자가 아닙니다.

효과를 주장하려면 실제 이미지·영상을 추가하고 새 세션과 사례 순서로 반복하며 사람 채점을 확보해야 합니다. 이 사례에 맞춰 스킬을 계속 수정한 뒤 미지의 평가로 제시하지 마세요. 개정 버전을 기록하고 다시 실행하거나 별도 보류 사례를 사용합니다.

## 실제 장면

실제 적용 근거는 합성 비교와 구분해 `real/`에 둡니다. 게임 버전, 의도, 조건, 최초·후속 캡처, 채택·기각한 수정과 실제 과제 검사를 기록합니다. 근거 있는 유지 결정도 유효합니다. 사람이 기록된 과제를 수행하기 전까지 이해도와 선호는 미검증입니다.
