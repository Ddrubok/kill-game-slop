## 자료와 실행

[출처 기록](provenance.json)의 소스 커밋은 `974cb39bcc716815aee79117f4f710b367454050`입니다. 새 자료는 실제 코스메틱 표시·CSS·문구 함수, 주입한 외형 조합 3개와 [380px](packet/cosmetics/cosmetics-380.png)·[960px](packet/cosmetics/cosmetics-960.png) 캡처입니다. 기본·우주 테마에서 같은 배지·칭호를 비교하고 빈 슬롯 예외를 포함했습니다. 실제 게임 스타일을 최소 호스트 마크업에 적용한 구성요소 장면이므로 자연 대국의 동작을 입증하지 않습니다. 자료 고정 전 실제 player-banner 클래스·스타일을 포함하도록 실행 장면을 수정했습니다. 초안의 어두운 글자 문제는 실행 장면의 오류였으며 게임 결함으로 보고하지 않았습니다. 초안 이미지는 평가자에게 전달하지 않았습니다.

승급 구성요소는 **이미 검토한 대조 사례**입니다. 11월 5일 관찰을 보존해 사용했으며 중복·오래된 콜백, 대기 선택·모션 줄이기 신호 문제는 새 아트 결함이 아닙니다. 아트 기준서, 대사 분기, 소리 재생, 움직임 영상, 계정 흐름, 후반 플레이는 제공하지 않았습니다. 보존할 사례와 자료 부족 사례를 함께 넣었으며, 숨은 정답표에 보편적인 화풍을 정해두지 않았습니다.

[초회 manifest](manifest.json)는 같은 입력 자료와 아트 요청을 고정합니다. 일반 조건은 요청만, 짧은 조건은 보존 원칙 문단을 추가로, 전체 조건은 설치 지침 11개 파일을 받습니다. 독립 Git 루트와 같은 모델·추론 설정을 사용했으며 채점 기준은 [실행 전에 해시로 고정](grading-frozen.json)했습니다. 호스트의 내부 맥락을 완전히 통제하지는 못합니다. 폴더 접근 제한은 작업 지침이며 OS 격리가 아닙니다.

초회 JSONL에는 명령은 있으나 이미지 열람 이벤트가 없습니다. 답변에는 이미지 검토 주장이 있지만 로그만으로 확인할 수 없습니다. 따라서 [시각 재확인](visual-recheck/manifest.json)은 **같은 요청과 기준**으로 새 대화 3개를 만들고 PNG 4장을 CLI `-i`로 직접 첨부했습니다. [실행 래퍼](visual-recheck/codex-entry.mjs), 이미지 해시, 원문 답변과 기록을 보존합니다. 두 묶음을 합산하거나 차이를 이미지 입력 방식의 통제된 효과로 해석하지 않습니다. 이전 답변을 새 평가자에게 전달하지 않았습니다.

[예비 채점 기록](grading.json)은 기준별 결과를 구분합니다. 답변을 읽은 조정 AI의 평가이며 맹검 사람 평가가 아닙니다. 전체 정확도 백분율을 만들지 않았습니다.

초회 아트 검토 세 조건은 모두 기록을 읽고도 알려진 승급 결함을 보고하지 않았습니다. 초회 전체 게임 검토는 중복·오래된 콜백을 보고했고 과거 증거와 새 재현을 명시적으로 구분했습니다. 아트 요청은 현재 표현에 초점을 두고 대조 사례는 과거 기록이어서 범위 차이가 섞입니다. 일반적인 발견율 순위를 뜻하지 않습니다. 다음 진단 시험에서는 반드시 검토할 장면을 실행 전에 명시할 필요가 있습니다.

어느 조건도 팔레트 통일이나 빈 배지·칭호의 프레임 강제 표시를 요구하지 않았습니다. 오래된 사전의 “스테이지 10” 문구를 Explorer의 실제 해금 조건으로 오판한 답변도 없었습니다. 다만 마지막 사례는 최종 답변에서 명시적으로 다루지 않았습니다. 침묵이 올바른 진단의 증거는 아니므로 **오판을 하지 않음**과 **보존 판단을 입증함**을 나눠 기록했습니다.

초회 일반 요청은 필요한 의미 관계를 확정하지 않은 채 배지 그림·이름의 불일치를 주장하고 문양 교체를 제안했습니다. 저장 흐름이 없다고 인정하면서 동기화 문구 수정도 제안했습니다. 근거가 부족하거나 분류가 약한 제안이며, 독립적으로 입증된 오탐이라고 단정하지 않았습니다. 이미지 첨부 조건에서는 이 제안들이 반복되지 않았습니다. 검토 세션은 입력·설치 지침을 수정하지 않았으며 범위 밖의 필수 변경을 실행하지 않았습니다.

모든 아트 조건이 380px에서 칭호가 사라지는 점을 찾았습니다. 표시 차이와 CSS 원인은 확인됩니다. 그러나 의도된 반응형 설계나 실제 설정 흐름의 약속을 위반하는지는 미확정입니다. 일부 답변은 확인된 불일치라고 불렀지만 전체 게임 검토는 결함 여부를 보류했습니다. 이를 **실제 설정·대국 맥락이 필요한 가설**로 유지하며 새 게임 결함이나 채점 성공 항목으로 추가하지 않았습니다. 접근성·배치 대안도 선택적 제안입니다. 이번 스킬 개발로 게임 코드를 수정하지 않았습니다.

## 실제 참조 읽기와 변경 범위

전체 조건은 모두 `SKILL.md`를 읽었습니다. [경로 기록](routing.json)은 성공했고 잘리지 않은 `Get-Content` 이벤트를 인용하며 파일명 나열은 읽기로 세지 않습니다. 숨은 호스트 맥락이 아닌 관찰 가능한 로컬 읽기에 대한 결과입니다.

작은 문구 작업은 아트·전체 게임·행동·실행·에디터·예시·인계 참조를 읽지 않았습니다. 진입 문서는 **공백 기준 1,397단어로 이번 변경 전후 동일**합니다. 기존 조건부 참조 두 곳에 표본 선정 원칙만 추가했으며 설치 파일은 11개입니다. 작업별 총량으로 지침 부담만 분리할 수 없고 일반 요청 문구 수정 대조군도 없습니다. 호스트가 강제하는 읽기 한도나 안정적인 절감을 주장하지 않습니다.

## 반영한 변경과 남은 범위

README 앞부분에 현재 기능·예시를 넣고 과거 측정의 버전을 명시했으며 긴 이력을 한·영 문서로 분리했습니다. 큰 목록은 개체·계열, 역할, 등급, 상태, 표시 맥락별로 묶고 대표·예외 사례와 선정 이유·제외 범위를 남깁니다. 고정 개수나 전체 목록 정상 판정을 강제하지 않습니다. 이번 실험은 카드 100장·캐릭터 50종의 표본 선정 자체를 검증하지 않았습니다.

답변에서 진단 범위와 분류의 한계가 드러났지만 기존 지침에도 근거 부족 시 가설로 남기고 의도된 맥락과 비교하라는 원칙이 있습니다. 칭호 사례 전용 체크리스트를 추가하면 이를 반복하게 됩니다. 따라서 설치 지침에는 요청된 짧은 표본 선정 안내만 반영했습니다. 다음 단계에는 새로운 게임, 요청 범위에 맞춘 명시적 결함 대조 사례, 실제 서사 분기와 사람의 판정이 필요합니다.
