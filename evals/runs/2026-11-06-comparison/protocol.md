# Comparison protocol frozen before outputs

The user explicitly requested the previously deferred comparison on 2026-11-06. This authorizes independent evaluator sessions for this task, without changing the project's persistent solo-agent setting. The shared Astra-team runner starts three fresh ephemeral Sol sessions, each with its own working directory. Requested model: `gpt-6-sol`; reasoning: `medium`; concurrency: three. No reviewer gets other responses, judge keys or historical results. The skill is frozen for this comparison.

Each condition receives the same concatenation, in the same order, of 12 C, four U, four V and six S cases (26 total). Source hashes and condition file hashes are in `manifest.json`. These are previously authored synthetic records. They are not held-out real game inputs, executable projects, video or user trials. One replicate per condition does not establish a stable ranking.

Generic gets the common request, including evidence/scope and per-case reporting instructions. Brief adds the existing preservation/evidence instruction. Full gets the exact skill snapshot plus conditional references. Mentions of skill names in scenario text do not activate installed skills in any condition. Thus generic is a reasonably scoped review baseline, not an uninstructed model.

The local CLI wrapper uses per-process `--ignore-user-config`, disables apps/skill search/web search, and sets `skills.include_instructions=false` and `skills.bundled.enabled=false`. The host's safety/system instructions and applicable project instructions remain. No user settings or credentials are changed. A separate probe under these final flags reported no supplied skill catalog. An earlier feature-flag-only probe still received the catalog, so that configuration was rejected before the comparison. This is input control and later trace auditing, not a filesystem security boundary.

Configuration basis: [official skill settings](https://learn.chatgpt.com/docs/config-file/config-reference#skillsinclude_instructions) and [local skill controls](https://learn.chatgpt.com/docs/build-skills#enable-or-disable-local-codex-skills), plus installed Codex CLI 0.167.0 help. Host/model instructions not exposed by CLI are not claimed identical byte for byte.

Freeze raw responses and JSONL traces before grading. A separate Sol judge receives anonymized response labels, the cases and the preregistered criteria. The coordinating author also checks each response and reconciles disagreements. Both are AI judgments, not independent human scoring. Criterion matches concern substantive reasoning, not exact labels or wording. A stated next check is not a claim it ran.

For each case record: expected decision, supported reasoning, preservation harm, unsupported observation/measurement/implementation claims, unauthorized action recommendations and actionable next checks. Aggregate these dimensions separately. Preserve all non-passes and scoring disagreements. Record usage from `turn.completed` and process elapsed time separately; input totals include reported cached tokens, and timing includes startup/latency/tool work. Do not infer dollar costs, measured human comprehension or actual repair success. Those fields remain unmeasured.
