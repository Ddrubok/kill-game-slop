## Decisions

The report's useful core is to **make observable evidence more concrete and provide usable specifications when edits cannot be executed**. The skill already covers genre preservation, accessibility, truthful state cues and engine-specific checks, so strengthening execution criteria is more appropriate than a complete redesign.

GI, MDA and similar scores were assigned without experimental data or a validated scale. They are not quality measurements or evidence of improvement. Claims such as “industry-leading” or “mandatory defects” are also unsupported by the supplied material.

| Proposal | Decision and application |
| --- | --- |
| Concrete slop catalog | Partially adopted. Linked ten common candidates to evidence, small repairs and legitimate counterexamples; no target of 70 items |
| Add triggers, file_patterns and tools | Not adopted. These are not standard skill fields and do not guarantee discovery across hosts. Retained valid frontmatter and clarified usage conditions in description |
| Editor-edit specifications | Adopted. Added target/evidence/change/scope/preservation/verification/status template and conditional engine checks |
| Copy-and-run engine scripts | Deferred. Without a specific engine version, project and assets, generic snippets risk unverified APIs and broad edits. Generate and verify against the actual environment when needed |
| Depth, particle-count or keyword scanner | Deferred. Depth 10, a particular font or “Tap to continue” alone cannot establish a defect. Reconsider after repeated real diagnostic tasks and normal/defective examples exist |
| Multimodal verification | Adopted: record conditions, separate observation from inference, compare under matching conditions and check related stress cases. Do not claim motion/audio/performance verification from a still image |
| Presentation budget | Adopted in principle. Compare repeated routine cues with meaningful climaxes, without requiring routine cues always to be weaker |
| Ban all scene-text edits | Not adopted. Small verifiable edits to readable source remain allowed; distinguish them from binary/generated-file edits or broad regex changes |
| Accessibility as a governing principle | Retained and strengthened existing principles. Connected redundant information channels and motion-setting preservation to concrete counterexamples. One screen check does not prove standards compliance |

Metadata basis: [Agent Skills specification](https://agentskills.io/specification). Name and description are required; scripts and references are optional. Absence of executable code is not itself a skill defect.

## Scope and verification limits

SKILL.md received core decision rules and reference links only; detailed cases and editor specifications live in references. Both READMEs explain the references' roles.

Verification covers skill format, internal document links and consistency with the installed copy. No real game project or engine runtime was used for compatibility/usability testing. New cases are judgment examples, not measured outcomes.
