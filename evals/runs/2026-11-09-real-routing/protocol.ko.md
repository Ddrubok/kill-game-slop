# 실제 게임 검토와 참조 선택 예비 평가 — 2026-11-09

[English](protocol.md)

실행 전에 입력 자료·설치 지침·채점 기준·요청을 고정합니다. 공유 Astra 실행기로 gpt-6-sol medium 새 세션 5개를 실행합니다. 자동 스킬 지침·앱·검색은 끕니다. 일반 요청·짧은 지침·전체 스킬로 아트·콘텐츠를 검토하고, 전체 스킬로 작은 문구 수정과 전체 게임 검토를 추가합니다. 입력 자료는 모두 같으며 전체 조건만 설치 지침을, 짧은 조건만 보존 원칙 문단을 받습니다. 아트 작업 요청은 나머지 내용이 같습니다. 답변과 채점 기준은 전달하지 않습니다. 각 작업 폴더에 독립 Git 루트를 둡니다. 접근 제한은 작업 지침이며 OS 격리는 아닙니다.

새 실제 게임 자료는 체스 알까기의 코스메틱 테마·상태 변형, 실제 표시 문구와 소스입니다. 승급 문제는 과거 증거를 사용한 기검토 대조 사례라고 명시합니다. 하나의 고정 게임이며 새로운 게임 여러 개나 자연스러운 플레이가 아닙니다. 새 아트 결함을 발견했다고 전제하지 않습니다. 아트 기준서·대사 분기·영상·소리·후반 플레이는 제공하지 않으며, 근거를 넘는 주장은 과장으로 기록합니다.

기존 결함 누락, 정상 사례 오판, 불필요한 필수 수정 제안, 보존과 판단 보류를 고정 기준으로 기록합니다. 답변을 본 조정 AI가 예비 채점하며 맹검 사람 평가나 통계적 유의성을 주장하지 않습니다. 기준 밖의 새 발견은 별도 근거로 판단하며 분모에 몰래 추가하지 않습니다.

완료 이벤트의 입력·캐시 입력·출력 토큰과 실행기 경과 시간을 기록합니다. 비캐시 입력은 입력에서 캐시를 뺀 값, 총 토큰은 입력과 출력의 합입니다. 원본 JSONL과 실패를 보존합니다. 명령 기록에서 실제 참조 읽기와 부분·잘림 여부를 확인하며 답변의 자기 보고만으로 읽었다고 세지 않습니다. 파일 변경 범위와 정확한 문구 수정을 확인합니다. 작업별 수행량이 다르므로 서로 다른 범위의 총량을 지침 부담 비교로 해석하지 않습니다. 조건당 1회로 안정적인 절감·금전 비용·정확도 우위를 주장하지 않습니다. 11월 6일 결과는 이 버전을 측정하지 않았습니다.

확인하려는 경로는 작은 문구 → 표현 참조, 아트 → 아트·콘텐츠 및 필요한 표현 참조, 전체 → 전체 게임 및 필요한 영역 참조입니다. 추가 읽기도 숨기지 않고 기록하며 자동으로 결함 판정하지 않습니다. 답변에서 일반화할 수 있는 지침 누락이 드러날 때만 보완합니다.
